# 配方总览

本模组 `src/main/resources/data/neoecoprototype/recipe/` 下的全部配方，共 **169 条**。
材料名取自各 mod 自带的 `zh_cn` 语言文件（我们自己的键优先），缺中文退回英文，再退回 id。

怎么读这张表：

- `x2` = 该材料需要的数量；`#` 开头的是标签，任意匹配物品即可（如羊毛、原木）。
- 用 `/` 分隔的一项是可替换槽位。
- `条件` 一列只写额外需要的 mod；空着表示只依赖 AE2 + eco，装了就会出。
- `文件` 一列就是配方 JSON 在数据包里的路径，改数值改那里。

不在这一份清单里的两件事：处理器装配室还能从 AE2 压印器配方**派生**出部分处理器配方（派生规则见 `docs/processor-assembler-recipes.md`）；KubeJS 与整合包自己在运行时增删的配方也不在这里，这里只数数据包文件。

音乐那一族（录制机 / AE 唱片机 / 数据唱片）从 1.4.9 起整族对玩家隐藏，三条配方文件已出包，所以不在这 169 条里。
