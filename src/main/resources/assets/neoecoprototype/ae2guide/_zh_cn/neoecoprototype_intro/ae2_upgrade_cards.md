# AE2 → L1 升级卡

对匹配的 L1 方块或线缆部件使用卡片，即可替换为对应附属的供应器或接口。原有样板或接口设置会随之保留。

| 卡片 | 转换结果 |
|---|---|
| <ItemImage id="neoecoprototype:ae2_pattern_provider_to_l1_card" scale="3" /> | L1 样板供应器 |
| <ItemImage id="neoecoprototype:ae2_interface_to_l1_powered_card" scale="3" /> | L1 供能接口 |
| <ItemImage id="neoecoprototype:ae2_interface_to_l1_superconductive_card" scale="3" /> | 盈能超导接口 |
