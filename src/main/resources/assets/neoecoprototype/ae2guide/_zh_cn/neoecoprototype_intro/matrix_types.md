# 支持的存储矩阵

这一页把本模组能注册进 [L1 存储系统](storage_system.md) 的矩阵放在一处对照：**先按要存的资源选系列，再比容量、类型上限与需要的模组**。每一族的细节在各自的页里。

## 先看要存什么资源

| 要存储的资源 | 矩阵系列 | 需要的模组 |
|--------------|----------|------------|
| 物品 | 常规物品矩阵 | — |
| 流体 | 常规流体矩阵 | — |
| Mekanism 化学品 | 化学品矩阵 | Mekanism + Applied Mekanistics |
| 单种资源、要装得下海量 | 小宗存储矩阵 | MEGA Cells（化学品小宗另需 Applied Mekanistics） |
| Forge Energy（FE） | FE 存储矩阵 | AppliedFlux |
| Mekanism 乏燃料 | 乏核废料存储矩阵 | AE2 Omni Cells + Mekanism + Applied Mekanistics |
| 多种 AE 资源混装 | 全能 / 复合全能 / 量子全能 | AE2 Omni Cells |
| 一种资源、容量不限 | 无限存储矩阵 | — |
| 不存东西、自己长货 | 奇点元件、陨石粉元件、自产矩阵 | 自产那一档要 KubeJS |

## 容量、类型上限与待机

| 系列 | 档位 | 类型上限 | 待机耗电 |
|------|------|----------|----------|
| 常规物品 / 流体 | 1K、16K、64K、1M、4M | 256 | 见 [L1 存储系统](storage_system.md) |
| 化学品 | 1K、16K、64K、1M、4M | 25 | 同上 |
| 小宗 | 单种海量，字节数不限 | 标记 3 种，装扩容卡后 10 种 | 同上 |
| FE | 1K、1M、4M（按字节计，1 字节 = 1 Mi FE） | 1 种 | 见 [FE 存储矩阵](flux_storage.md) |
| 乏核废料 | 1K、1M | 1 种 | 8 AE/t |
| 全能 | 1K、1M | 512 | 8 AE/t |
| 复合全能 | 1K、1M | 1024 | 8 AE/t |
| 量子全能 | 1K、1M | 不限类型 | 8 AE/t |
| 无限存储矩阵 | 容量不限 | 16 | 8 AE/t |
| 奇点元件 | 容量不限 | 1 | 1 AE/t |
| 陨石粉元件 | 容量不限 | 1 | 1 AE/t |
| 自产矩阵（KubeJS） | 容量不限 | 1 | 1 AE/t |

- 表里的"1K / 16K / 64K / 1M / 4M"数的是**字节**，不是直接的资源数量；每种资源能装多少由"字节 ÷ 每类型字节"决定。**物品、流体与化学品的小档比自己的名字多 25%**——1280、20480、81920 字节，所以 AE2 原版的 1K 仓（1024 字节）同名之下装得比我们少；FE 与混装那几族仍是 1024。
- 混装一族（全能、复合全能、量子全能）接收当前游戏里注册的全部 AE 资源类型：物品、流体、能量、化学品可以共用一只。三族容量档位相同，区别就在类型上限那一列。
- 小宗那一族的字节数标为不限，真正限制它的是标记位：一只小宗仓只装你标记的那几种，每标记一种还要求链条上备有对应形态。

详见 [小宗存储矩阵](small_bulk_matrices.md)。
- 奇点元件、陨石粉元件与自产矩阵**什么都不吃**：往它们推东西一律拒收，库存按世界时间自己长。

详见 [L1 奇点元件](singularity_cell.md)。

## 哪些插得进我们这台 L1 驱动器

驱动器按等级比较：**只收等级不高于自己的矩阵**。我们 L1 的等级数是 0，所以 eco 的 L4/L6/L9 兼容矩阵插进我们这台会被拒收——这一档的造价本来就在量子之下，不打算当高阶仓的宿主。反过来 eco 那边能不能收我们的矩阵，取决于它自己的比较规则，我们这边没有读数以担保。

## 用 KubeJS 加自己的矩阵

整合包可以注册新档位、新材质，也可以造**自产矩阵**（`.grows(单批产量, 间隔刻)`：每隔那么久世界刻给出一次绑定的物品/流体/化学品，任意 mod 的资源都行）。见 [KubeJS 支持](kubejs.md)。
