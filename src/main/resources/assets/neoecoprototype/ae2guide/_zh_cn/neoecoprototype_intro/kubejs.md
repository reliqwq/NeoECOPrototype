# KubeJS 支持

KubeJS 是可选模组。安装后，整合包作者可以：

- 在启动脚本注册自定义存储矩阵（`neoecoprototype:storage_matrix` 与 `neoecoprototype:infinite_storage_matrix` 两种 builder 类型），支持自定义容量、类型数、材质与绑定资源；
- 在服务端脚本增删改本模组配方——处理器装配器支持按字段删除配方与原始 JSON 新增。

完整示例见本模组仓库的 `docs/kubejs.md` 与 `docs/kubejs-example.js`。
