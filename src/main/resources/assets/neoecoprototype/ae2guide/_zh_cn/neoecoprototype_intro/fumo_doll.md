# 玩偶

玩偶是坐在方块格里的坐姿布偶，脸、衣服、袖子直接取自某位玩家的皮肤，所以每个人做出来的玩偶都长得不一样。

放下来的玩偶方块会照亮周围。

亮度 15 级，也就是满亮度。

## 合成

在 [L1 处理器装配室](processor_assembler.md) 里用三件套子系统主机合成。

先在样板编码台编一张"三料一出品"的处理样板：三个材料格放三台主机，输出选玩偶。

再把样板插进装配室即可。

| 玩偶 | 材料 |
|------|------|
| reliqwq 玩偶 | L1 可拓展存储子系统主机 + L1 计算子系统主机 + L1 合成子系统主机 |
| Yang120 玩偶 | L4 可拓展存储子系统主机 + L4 计算子系统主机 + L4 合成子系统主机 |
| kouooki 玩偶 | 粉色染料 + 干海带 + 棕色蘑菇 |

## 用指令获取任何人的玩偶

创造模式或 OP 可以直接取任意玩家的玩偶：

```
/prototypefumo <玩家名>
```

名字会走原版玩家头颅那套档案查询，所以不要求对方在线。

查不到时玩偶会用占位皮肤，不会报错。

指令可以在服务端配置里整个关掉。

开关是 `fumo_command_enabled`，默认开启。

## 佩戴

玩偶可以放进头盔栏戴在头上：

- **所有玩偶**：夜视，持续 30 秒，戴着会自动续期。
- **具名玩偶**（reliqwq、Yang120、kouooki）：额外护甲加成，仅戴在头上时生效，名字以本模组的绿色显示。

reliqwq 与 Yang120 是 +4 护甲值、+2 护甲韧性；kouooki 是 +1 护甲值、+5 护甲韧性。

右键是放置方块，所以要把玩偶戴到头上需要把它拖进头盔栏。
