# 小宗存储矩阵

**小宗存储矩阵**是<ItemLink id="ae2:drive" />那一族里的极端成员：每种近乎无限，默认 **3 种**，用扩展卡升到 **10 种**。

| 项目 | 数值 |
|------|------|
| 类型上限 | 3，装上扩展卡 10 |
| 单类型容量 | （终端里显示成 9.2E） |
| 需要的前置 | MEGA Cells=；化学品另需 Mekanism 与 Applied Mekanistics |

## 分区

在 AE2 的元件工作台里编辑；流体盘与化学品盘各自按自己的键类型分区。

## 升到 10 种

在工作台盘与**扩展卡**一起合成。扩展卡配方：4 绿晶晶格 + 4 颗 MEGA Cells 1M 元件 + 1 盈能超导锭。

## 拆回

流体与化学品这两只基础盘可以拆回，退回外壳与一颗 1M 元件。
> **注意**：**物品那只基础盘与三只扩展版都没有拆解配方**。扩展版不支持拆卸。

## 这一族包含

> 下面这些物品**只有装了 MEGA Cells 才会注册**（化学品那两只另需 Mekanism 与它的 AE2 桥接模组 Applied Mekanistics）。
| 名字 | 是哪一类 |
| --- | --- |
| ECO - L1 小宗存储矩阵（3种类型） | 物品盘，基础 |
| ECO - L1 小宗扩展存储矩阵（10种类型） | 物品盘，装卡后的产物 |
| ECO - L1 小宗流体存储矩阵（3种类型） | 流体盘，基础 |
| ECO - L1 小宗流体扩展存储矩阵（10种类型） | 流体盘，装卡后的产物 |
| ECO - L1 小宗化学品存储矩阵（3种类型） | 化学品盘，基础 |
| ECO - L1 小宗化学品扩展存储矩阵（10种类型） | 化学品盘，装卡后的产物 |
| L1 小宗扩展卡 | 3 种升到 10 种用的卡，配方见上一节 |
| ECO - L1 小宗存储矩阵外壳 | 物品盘的外壳 |
| ECO - L1 小宗流体存储矩阵外壳 | 流体盘的外壳 |
| ECO - L1 小宗化学品存储矩阵外壳 | 化学品盘的外壳 |
