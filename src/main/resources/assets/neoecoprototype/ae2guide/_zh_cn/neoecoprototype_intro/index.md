# Neo ECO Prototype

Neo ECO Prototype 把 Neo ECO AE Extension 的后期内容带到 **L1 前期**。三大系统（存储 / 计算 / 合成）的耗电是 eco L4 同级的 **1/8**。

没玩过 eco 也可以读：这三套东西就是**能建得更长、自带能量与冷却的 AE2 版本**——存储对应<ItemLink id="ae2:drive" />，合成对应合成 CPU 与样板供应器，计算负责给自动合成提供线程与并行。

| 想做什么 | 看哪一页 |
|----------|----------|
| 建一套前期就能用的存储网络 | [L1 存储系统](storage_system.md)（矩阵挂进网络，自带能量缓冲） |
| 用样板自动化处理器 | [L1 处理器装配室](processor_assembler.md)（前期没有压印器也能做出处理器） |
| 用 eco 的大型集成工作站跑我们的处理器配方 | [L1 处理器装配卡](processor_assembly_card.md)（同一族配方搬到工作站上，样板按 64 倍编码） |
| 大宗囤少数几种资源 | [小宗存储矩阵](small_bulk_matrices.md)（3 种起步，装卡到 10 种） |
| 把 FE 留在网格里 | [FE存储矩阵](flux_storage.md)（1K / 1M / 4M，需要 AppliedFlux） |
| 把一整块电量存进网格 | [盈能能源元件](energized_energy_cells.md) |
| 不搭物质聚合器也拿到奇点 | [L1 奇点元件](singularity_cell.md) |
| 提升合成吞吐 | [L1 计算系统](computation_system.md) 与 [L1 合成系统](crafting_system.md) |
| 子网供电、大批量标记 | [L1 供能接口](powered_interface.md) 与 [盈能超导接口](superconductive_interface.md) |
| 用脚本注册矩阵与配方 | [KubeJS 支持](kubejs.md) |

两台接口都自带被动发电，但 AE2 每个网格只保留输出功率最高的那台——细节见[供能接口](powered_interface.md)那一页。

三合一联合体仍在早期开发，未收进本指南。
