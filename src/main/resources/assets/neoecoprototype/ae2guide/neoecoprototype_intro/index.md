# Neo ECO Prototype

Neo ECO Prototype brings Neo ECO AE Extension's late-game content forward to **L1 early game**. The three systems (storage / computation / crafting) idle at **1/8** of eco's L4 equivalent.

If you have never used eco: think of these as **longer-buildable AE2 versions with their own power and cooling** - the storage side stands where an <ItemLink id="ae2:drive" /> would, the crafting side is a crafting CPU plus its pattern providers, and the computation side supplies the threads and parallelism autocrafting runs on.

| What you want | Where to read |
|---------------|----------------|
| A storage network you can build early | [L1 Storage System](storage_system.md) - matrices on the network, with its own energy buffer |
| Automating processors from patterns | [L1 Processor Assembler](processor_assembler.md) - processors before you have an inscriber |
| Running our processor recipes on eco's large station | [L1 Processor Assembly Card](processor_assembly_card.md) - the same family on eco's big station, patterns at 64x |
| Bulk storage of a few resources | [Small Bulk Matrices](small_bulk_matrices.md) - 3 types, 10 with the expansion card |
| Keeping FE inside the network | [FE Storage Matrices](flux_storage.md) - 1K / 1M / 4M, needs AppliedFlux |
| Parking a block of charge in the grid | [Energized Energy Cells](energized_energy_cells.md) |
| Singularities without building a Matter Condenser | [L1 Singularity Cell](singularity_cell.md) |
| More crafting throughput | [L1 Computation System](computation_system.md) and [L1 Crafting System](crafting_system.md) |
| Sub-network power, big markings | [L1 Powered ME Interface](powered_interface.md) and [Energized Superconductive Interface](superconductive_interface.md) |
| Registering matrices and recipes from scripts | [KubeJS support](kubejs.md) |

Both interfaces generate power passively, but AE2 keeps only the highest-output generator per grid - see the [L1 Powered ME Interface](powered_interface.md).

The combined three-in-one machine is still in early development and is not covered here.
