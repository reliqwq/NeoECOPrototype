# AE2 to L1 Upgrade Cards

Use a card on the matching L1 block or cable part to replace it with the corresponding addon provider or interface. Existing patterns or interface settings are carried over.

| Card | Converts to |
|---|---|
| <ItemImage id="neoecoprototype:ae2_pattern_provider_to_l1_card" scale="3" /> | L1 Pattern Provider |
| <ItemImage id="neoecoprototype:ae2_interface_to_l1_powered_card" scale="3" /> | L1 Powered Interface |
| <ItemImage id="neoecoprototype:ae2_interface_to_l1_superconductive_card" scale="3" /> | Energized Superconductive Interface |
