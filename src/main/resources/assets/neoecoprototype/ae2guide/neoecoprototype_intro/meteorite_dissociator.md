# Meteorite Core Dissociator

The **Meteorite Core Dissociator** turns an energized fluix crystal block into a spread of sky stone, dusts, crystals and other products. Put the crystal block in the large centre slot, fill the two baths with the fluids shown in the tanks, and power the machine. A catalyst in the small slot beside the core adds a permanent bonus and is never consumed.

## Automation faces

The first button in the panel opens this guide. The second opens the face configuration popup. Each of the six face buttons cycles through four modes:

| Colour | Mode | Automation |
|--------|------|------------|
| Gray | None | The face exposes no item, fluid or energy connection |
| Blue | Input | Items and fluids may go in, and the machine may receive FE |
| Orange | Output | Products may be pulled out; both baths remain input-only |
| Purple | Input and output | Both item directions are allowed; fluids and FE remain input-only |

New machines start with **every face blue (input)**. The question mark inside the popup opens this guide, the close button hides the popup, and the gear sets every face back to gray.
