# Energized ME Chest

The Energized ME Chest is a single-cell ME storage block with a **5,000 AE** buffer. It accepts AE2 storage cells and eco storage matrices in the same slot. The green <ItemLink id="neoecoprototype:ec1_me_chest" /> has the same functionality but accepts only AE2 cells and tier-1 matrices; the Energized ME Chest additionally accepts tier-4 and infinite resource matrices.

- Use one ME channel; the chest can pass up to **8 channels**.
- All six faces accept AE or FE, but the chest never supplies power to another network device.
- Right-click the **top** for a terminal. Online and powered, it shows the network; otherwise it shows only the installed cell.
- Right-click a **side or the bottom** for the cell slot and priority settings.
- Right-click the installed cell, or use the cog button, to open its cell workbench. Both AE2 cells and eco matrices can be partitioned there.
- Wrench it to rotate it; sneak while dismantling to keep its contents.

Idle draw is **1 AE/t plus the installed cell's own idle drain**. The front animation runs while the chest is powered with a cell installed.
