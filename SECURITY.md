# Security Policy

Neo ECO Prototype is a Minecraft mod and does not process account credentials or payment information.

If you discover a security issue involving the mod, do not publish exploit details in a public issue until maintainers have had a reasonable opportunity to investigate. Contact the repository maintainer through the private contact method listed on the GitHub profile.

Please include:

- affected Neo ECO Prototype version;
- Minecraft and NeoForge versions;
- a minimal reproduction, when safe to provide;
- relevant logs with private paths and credentials removed.

Dependency vulnerabilities should also be reported to the respective upstream project.
